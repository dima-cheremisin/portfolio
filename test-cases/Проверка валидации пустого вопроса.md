## ТК-002 — Проверка валидации пустого вопроса

**Приоритет:** Низкий  
**Тип проверки:** Негативный  
**Окружение:** iPhone 13 mini / iOS 26.4.2 / Telegram v12.7

### Предусловия

- Пользователь авторизован в Telegram.
- Открыто модальное окно «Создание опроса».

### Тестовые данные

**Вопрос:**  
Пустое значение

**Варианты ответа:**

1. `Да`
2. `Нет`

### Шаги

1. Оставить поле «Вопрос» пустым.
2. Ввести первый вариант ответа `Да`.
3. Ввести второй вариант ответа `Нет`.
4. Нажать кнопку «Создать».

### Ожидаемый результат

Опрос не создаётся.

Отображается сообщение:

`Укажите вопрос`
