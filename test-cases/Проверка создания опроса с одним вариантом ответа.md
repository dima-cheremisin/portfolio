## ТК-003 — Проверка создания опроса с одним вариантом ответа

**Приоритет:** Низкий  
**Тип проверки:** Негативный  
**Окружение:** iPhone 13 mini / iOS 26.4.2 / Telegram v12.7

### Предусловия

- Пользователь авторизован в Telegram.
- Открыто модальное окно «Создание опроса».

### Тестовые данные

**Вопрос:**

`Кто пойдет гулять?`

**Вариант ответа:**

`Я`

### Шаги

1. Ввести в поле «Вопрос» текст `Кто пойдет гулять?`.
2. Добавить вариант ответа `Я`.
3. Нажать кнопку «Создать».

### Ожидаемый результат

Опрос не создаётся.

Отображается сообщение:

`Требуется указать не меньше двух вариантов ответа`

### Фактический результат

Опрос создаётся с одним вариантом ответа.
