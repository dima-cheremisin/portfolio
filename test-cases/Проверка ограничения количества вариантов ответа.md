
## ТК-005 — Проверка ограничения количества вариантов ответа

**Приоритет:** Низкий  
**Тип проверки:** Негативный  
**Окружение:** iPhone 13 mini / iOS 26.4.2 / Telegram v12.7

### Предусловия

- Пользователь авторизован в Telegram.
- Открыт экран создания опроса.

### Шаги

1. Открыть экран создания опроса.
2. Ввести вопрос.
3. Добавить 12 вариантов ответа.
4. Попытаться добавить 13-й вариант ответа.

### Ожидаемый результат

13-й вариант ответа не добавляется.

Пользователю отображается сообщение о достижении максимального количества вариантов ответа.
