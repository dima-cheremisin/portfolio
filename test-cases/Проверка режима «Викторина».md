## ТК-004 — Проверка режима «Викторина»

**Приоритет:** Высокий  
**Тип проверки:** Позитивный  
**Окружение:** iPhone 13 mini / iOS 26.4.2 / Telegram v12.7

### Предусловия

- Пользователь авторизован в Telegram.
- Открыто модальное окно «Создание опроса».

### Тестовые данные

**Вопрос:**

`Сколько наград получило агентство Red Collar на Ruward Award 2026?`

**Варианты ответа:**

1. `4`
2. `5`
3. `6`

**Правильный ответ:**

`5`

### Шаги

1. Ввести вопрос.
2. Добавить вариант ответа `4`.
3. Добавить вариант ответа `5`.
4. Добавить вариант ответа `6`.
5. Включить переключатель «Викторина».
6. Выбрать вариант `5` в качестве правильного ответа.
7. Нажать кнопку «Создать`.
8. Проголосовать за один из вариантов ответа.

### Ожидаемый результат

Опрос успешно создаётся в режиме «Викторина».

После голосования:

- отображается выбранный вариант;
- отображается правильный ответ;
- результат соответствует настройкам викторины.
