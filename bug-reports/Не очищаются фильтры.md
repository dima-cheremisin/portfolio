# Фильтры каталога не сбрасываются после повторного входа в аккаунт

**Приоритет:** Medium
**Severity:** Medium

**Окружение:** Edge 124, Windows 11, production, версия приложения 5.0.2

## Предусловия
Пользователь авторизован, находится в каталоге товаров

## Шаги воспроизведения
1. Открыть приложение в браузере Edge 124 на Windows 11
2. Войти в аккаунт
3. Перейти в каталог товаров
4. Применить фильтры
5. Выйти из аккаунта
6. Повторно войти в аккаунт
7. Проверить, остались ли фильтры применёнными

## Ожидаемый результат
Страница каталога открывается с настройками по умолчанию, без применённых фильтров

## Фактический результат
Фильтры остаются применёнными после повторного входа в аккаунт

## Дополнительная информация
- После очистки Local Storage проблема исчезает — указывает на то, что состояние фильтров хранится в Local Storage и не сбрасывается при logout
- В режиме инкогнито не воспроизводится — подтверждает связь с локальным хранилищем браузера, а не с серверной сессией
