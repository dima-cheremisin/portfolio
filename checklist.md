# Обнаруженные дефекты

## BUG-001 — Можно создать опрос с одним вариантом ответа

**Severity:** Medium  
**Priority:** Medium

### Предусловия

Пользователь находится в окне создания опроса.

### Шаги воспроизведения

1. Открыть создание нового опроса.
2. Ввести вопрос.
3. Оставить только один вариант ответа.
4. Нажать кнопку создания опроса.

### Ожидаемый результат

Опрос не создаётся.

Пользователю отображается сообщение об ошибке:

> Необходимо добавить минимум два варианта ответа.

### Фактический результат

Опрос успешно создаётся с одним вариантом ответа.

### Окружение

- iPhone 13 mini / iOS 26.4.2 / Telegram v12.7
- Windows 10 Pro v22H2 / Telegram Desktop v6.7.8 x64
